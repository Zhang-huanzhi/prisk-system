## 阶段定位与承接

v1.1.0 规则知识库全集已收口并归档于 [docs/versions/v1.1.0/](../versions/v1.1.0/README.md)。

本阶段承接 Task 018 所有者终裁留下的残余实现项与大纲核心规则实现规划：
1. **残余检测器与合同对齐**：
   - `code.bare_exception`：将 `except Exception` 从 Finding 集合中拆出，使运行时检测器严格符合卡片合同；
   - `code.unmanaged_open`：实现对 `Path.open` / `pathlib.Path.open` 属性调用的覆盖；
   - 已知框架基类映射表（[known-framework-bases.md](../rules/known-framework-bases.md)）的运行时检测器支持；
   - `Meta.fields` 嵌套列表细节可读性支持与 `unsupported_stage04_details` 缺口收窄；
   - 非空模型字段约束路径上对 `default=` 的可靠读取与判定；
   - 敏感配置方向判定支持；
   - 一票抬升：在复核评分侧联动读取登记册 `gatekeeper` / `gatekeeper_condition`。
2. **候选规则检测器落地**：
   - 从 20 条草稿卡片中筛选高价值规则（如 CSRF 豁免、ViewSet 动作变更、破坏性迁移等），分批实现 AST/Diff 检测器与构造测试；
   - 接入检测器并经构造测试通过后，方可将对应的 `lifecycle` 从 `draft` 晋升。
