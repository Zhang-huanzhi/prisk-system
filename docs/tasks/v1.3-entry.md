## 阶段定位与承接

v1.2.0 核心规则实现与三态引擎能力闭环已归档于 [docs/versions/v1.2.0/](../versions/v1.2.0/README.md)。

本阶段承接 [开发推进大纲](../standards/development-roadmap.md) 中的 **「v1.3.0 动态交互工作台与报告」** 目标，核心演进方向包括：

1. **运行时配置解耦**：
   - 规则启用开关（`enabled_rules`）、启发式权重（`rule_weights`）与规则内部判定阈值（`thresholds`）全面解耦；
   - 摆脱全 0 默认权重的过渡状态，支持针对不同审查场景（如安全加固、版本升级、日常审查）载入不同配置预设（Presets）；
   - 探索 `workflow.large_change_scope` 在动态阈值配置与项目模块映射支持下的落地。
2. **快照局部重跑机制**：
   - 复用已提取并持久化的 Git 三点 Diff（Stage03）与 Python AST 结构对象（Stage04）；
   - 在用户调整规则开关、权重或阈值时，无需重新克隆或重新解析语法树，仅局部重跑受影响规则的 Stage05 判定与 Stage07 评分。
3. **Web 看板交互增强与审查报告固化**：
   - 前端看板支持 29 条规则三态明细展开、缺口原因聚合筛选与 Gatekeeper 抬升事实展示；
   - 导出可交互/离线审查报告（Markdown/JSON），**报告强制固化本次运行的完整配置快照**（开关/权重/阈值），确保任何一次审查结论完全可追溯、可复现。
