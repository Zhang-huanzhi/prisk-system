## 阶段定位与承接

v1.3.0 动态交互工作台、快照局部重跑与可复现审查报告已归档于 [docs/versions/v1.3.0/](../versions/v1.3.0/README.md)。

本阶段严格承接 [开发推进大纲](../standards/development-roadmap.md) 中的 **「v1.4.0 规模型实证打靶与权重校准」** 三项核心目标（知识库中 2 张延后草稿卡片 `workflow.large_change_scope` 与 `data.django_transaction_boundary_changed` 按 [结构可行性筛选](../rules/structural-feasibility.md) 保持 `draft` 不变）：

1. **独立正式实证集抽样与批量运行**：
   - 在**严格物理隔离** v1.0.0 调研集（120 条）与 v1.1.0 先导试点集（16 条，[docs/evaluation/pilot-v1.1/](../evaluation/pilot-v1.1/README.md)）的前提下，构建独立的真实开源项目 PR 正式实证集；
   - 制定抽样协议与标注指南，批量执行静态结构分析并持久化产出。
2. **实证筛选与高噪规则治理**：
   - 统计 29 条规则在真实 PR 下的三态表现（`Hit / NotFound / Unanalyzed`）与人工核验准确率；
   - 识别低区分度或高噪声规则，实施权重降级或默认禁用；
   - 推动具备实证支撑的规则生命周期从 `implemented` 晋升为 `validated`。
3. **默认基线权重校准与论文实验数据产出**：
   - 打破过渡态全 0 权重，建立经实证数据支撑的合理默认权重推荐值（告别全 0 默认基线）；
   - 依托 `config.snapshot.v1` 固化可复现实验配置快照，产出毕业论文所需的量化对比、有效性验证与威胁分析数据。
