# 05 阶段结论与完成说明

## 结论

05 阶段实现了基于 `stage04.v1` 的四类最小结构规则。规则结果只表示需要复核的结构线索，不表示已经确认存在安全缺陷。

## 规则与证据

- `interface.signature_changed`：接口相关 Python 文件中的函数签名变化；
- `auth.permission_structure_changed`：认证/权限路径、权限装饰器或权限调用结构变化；
- `data.transaction_structure_changed`：模型、迁移或事务/数据库调用结构变化；
- `config.exception_structure_changed`：配置路径或异常处理结构变化。

每条 finding 包含规则 ID、场景、严重程度、文件路径、节点 ID、结构变化类型、Diff 行号和复核建议。测试协同只写入 summary 辅助字段。

## 限制

规则不读取审查评论、CI 或 `evaluation` 字段，不判断运行时授权、事务结果、配置值或接口兼容性。后续阶段再考虑评分、规则配置外置和展示层。
