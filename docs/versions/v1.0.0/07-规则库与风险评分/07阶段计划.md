# 07 阶段：规则库与风险评分

## 目标

在 05 阶段结构规则结果之上，加入透明、可重复、可调参数的复核优先级评分，并为 06 阶段看板提供配置重算和报告导出接口。

## 固定方案

- 规则命中按规则 ID 计权，不按 evidence 数量重复加分；
- 默认权重：接口 2、权限 3、数据事务 2、配置异常 1；
- 测试协同缺失作为辅助权重，默认 1；
- 默认等级阈值：30 为“建议复核”，65 为“优先复核”；
- 配置变化必须写入报告，保证同输入同配置可重复生成；
- 分数表示人工复核优先级，不表示缺陷概率。

## 交付

- `src/prisk/demo_service.py`：数据合并与评分；
- `src/prisk/scoring_cli.py`：批量生成 `stage07.report.v1`；
- 05 规则结果不被覆盖；
- 看板可调整规则开关、权重和阈值后重新分析。
