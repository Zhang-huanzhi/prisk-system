# 07 阶段结论与完成说明

07 阶段已完成透明评分闭环。系统读取 03/04/05 产物生成 `stage07.report.v1`，每条报告保留规则命中、结构证据、评分配置和等级阈值。归档源中未找到全量评分 JSONL；本目录保留运行 manifest 与可复核的汇总结果，不以看板演示数据替代全量产物。

## 结果

- 99 条可分析 PR 生成评分报告；
- 4 条规则均可纳入评分；
- 支持规则启用/关闭、权重调整、测试协同权重和等级阈值调整；
- 同一 PR 的配置变化可重新计算并导出 JSON/Markdown；
- 评分不使用 evidence 数量重复累加，避免大 PR 因结构节点多而机械放大；
- 分数是复核优先级，不是缺陷概率，也未使用独立标注集校准。
- 全量结果包含 99 条可分析 PR 和 21 条排除记录；共有 1,153 个 finding、12,416 条证据；等级分布为高 31、中 34、低 34；
- 全量评分 JSONL 重复生成后 SHA-256 一致，生产构建及生产依赖审计通过；
- 当前规则与权重适合教学演示和人工复核排序，不应作为自动缺陷判定。
