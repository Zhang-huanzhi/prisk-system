# 08 阶段：本地项目与分支审计闭环

## 目标

将看板从固定 NetBox PR 样本扩展为“加载本地 Git 项目 → 浏览分支 → 选择 base/head → 分析三点 Diff → 查看结构、规则和评分”的闭环。PR 与本地分支统一为 base/head 分析关系，规则有效性不在本阶段重新评价。

## 完成范围

- 本地路径加载、Git 根目录校验、稳定项目 ID、默认分支和本地/远程跟踪分支发现；
- `POST /api/projects/load`、`GET /api/projects/<id>/branches` 和 `POST /api/branch-analysis`；
- 动态分支流水线复用 03 阶段三点 Diff、04 阶段 AST、05 阶段规则和 07 阶段透明评分；
- 首次入口改为项目选择页，浏览器保存最近项目，冻结 NetBox 作为显式样本入口；
- 分支审计工作区继续提供概览、代码变更、风险规则和评分配置四个视图；
- 不切换分支、不读取未提交改动、不修改 03 至 07 阶段原始 JSONL。

## 固定边界

当前分析结果只保留在页面和进程内，可导出但不写数据库。评分表示人工复核优先级，不表示缺陷概率；当前仍是本地离线人工复核工具。
