## 基线能力

- 本地 Git 项目加载和本地/远程跟踪分支发现；
- base/head 三点 Diff、Hunk、行级变更和 Python AST 结构证据；
- 四类最小规则、透明评分和人工复核优先级；
- 冻结 NetBox 样本 API 与本地分支审查 API；
- Next.js 看板、阶段 CLI、旧脚本入口和已存在的公开 import。

v1.0.0 的历史实现曾采用 `src/prisk` 与 `apps/web` 布局；待发布工作区已整理为 `backend/` 与 `frontend/`，并在 `backend/prisk/` 内分层。历史路径只用于解释基线，不是当前开发入口。

## 版本边界

规则命中和评分不表示确认缺陷或缺陷概率。人工评论、多人协作、GitHub 账号、云端同步和数据库不属于 v1.0.0。

## 冻结产物现状

- 02 阶段保留 NetBox 与 Saleor 的脱敏采样记录、汇总、场景表和采样脚本。
- 03、04 阶段保留 pilot 与全量 JSONL、manifest；04 阶段另含结构质量审计结果。
