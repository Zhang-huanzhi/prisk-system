# 02 阶段计划：PR 采样与风险场景冻结

> 本计划根据阶段结论和冻结产物回溯整理，用于 v1.0 归档；不代表当时存在单独维护的计划文件。

## 目标

通过公开后端项目已合并 PR 的试采样，选择主实验项目和对照项目，冻结可分析样本及后续规则研究的风险场景。

## 范围

- 比较 NetBox 与 Saleor 的样本规模、场景重复度和代码可解析性；
- 选定 NetBox 为主项目、Saleor 为对照项目；
- 对 NetBox 按时间、贡献者和改动规模采样 120 条 PR；
- 记录 base/head、变更事实、评价证据及排除原因；
- 确定接口行为、认证与权限、数据与事务、配置与异常四类场景；
- 将测试协同保留为辅助证据，不纳入四类场景。

## 完成条件

- 120 条样本的基础版本、目标版本和累积差异可恢复；
- 明确区分 99 条可分析记录与 21 条排除记录；
- 四类场景在样本中重复出现且具备后续结构分析条件；
- 不将结构变化或评价线索直接解释为已确认缺陷；
- 冻结原始输入，不在后续阶段重新采样或覆盖。

## 阶段结论

NetBox 确定为主实验项目，Saleor 保留为对照。正式采样和场景统计见本目录的 [阶段结论](02阶段结论与完成说明.md)、[NetBox 场景表](NetBox场景表.md)、[NetBox 调研](NetBox调研.md) 和 [Saleor 场景表](场景表.md)。
