## 项目决定

NetBox 作为主项目的依据是样本和场景覆盖，而不是审查评价标签更完整。NetBox 有 99 条可分析 PR，接口、认证与权限、数据与事务、配置与异常四类场景都达到纳入标准；Saleor 只有接口行为和数据与事务两类达到纳入标准。因此，NetBox 更适合验证规则引擎在多个后端风险场景中的覆盖能力。

NetBox 的限制也需要保留：其领域对象包括站点、设备、接口、IP、VLAN 和租户，业务理解成本高于 Saleor；审查评论、CI 和合并后修复证据仍然不完整。主项目选择不能解释为“NetBox 的历史标签更可靠”，而应解释为“NetBox 的可分析样本和风险场景更充分”。

## 02 阶段规则范围

主项目后续纳入以下四类规则场景：

- 接口行为；
- 认证与权限；
- 数据与事务；
- 配置与异常。

测试代码是否与业务代码协同修改作为评分辅助证据，不单列为风险场景。复杂业务语义、运行时并发、线上性能和整体方案合理性不在本阶段规则范围内。
