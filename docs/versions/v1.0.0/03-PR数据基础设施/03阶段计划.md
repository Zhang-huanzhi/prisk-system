# 03 阶段：PR 数据基础设施与统一变更表示

## 阶段目标

将 02 阶段冻结的 NetBox PR JSONL 转换为可复查、可重复生成、供后续 AST 和规则阶段使用的统一变更对象。

```text
PR 元数据
→ base/head 提交校验
→ base...head 累积 Diff
→ 文件角色识别
→ Hunk 与行级变更
→ 统一 JSONL 对象
```

## 本阶段范围

- 读取 `NetBox/netbox-survey.jsonl`；
- 校验 `base_sha` 和 `head_sha`；
- 使用 `base_sha...head_sha` 读取累积 Diff；
- 识别新增、删除、修改、重命名、复制和二进制文件；
- 保存 Hunk、行号和行级变更；
- 区分 `business`、`test` 和 `other` 文件；
- 输出 `stage03.v1` JSONL 和批处理清单。

本阶段不实现 AST 结构识别、风险规则、评分或 Web 页面。

## 执行顺序

1. 先处理 PR 179、19、226，分别覆盖小、中、大改动；
2. 三条真实 PR 稳定解析后扩展到全部 120 条输入；
3. 99 条可分析 PR 输出完整变更对象；
4. 21 条排除记录保留为 `excluded`，不重新采样；
5. 将统一对象和校验结果交接给 04 阶段。

## 完成门槛

- 三条代表性真实 PR 全部解析成功；
- 全量结果包含 99 条 `ok` 和 21 条 `excluded`；
- 统一对象可独立提供文件角色、增删行数、测试协同和 Hunk 行号；
- 重复运行输出稳定；
- 单条 Git 或输入错误不会阻断其他记录；
- 02 阶段原始 JSONL 和仓库工作区未被修改。
