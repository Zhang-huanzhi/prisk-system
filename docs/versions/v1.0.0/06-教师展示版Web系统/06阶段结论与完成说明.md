# 06 阶段结论与完成说明

06 阶段已完成冻结 NetBox PR 代码审计工作区。页面使用真实 03/04/05/07 产物，默认展示 PR 226；PR 列表只作为导航，所有概览、代码、规则和评分内容都属于当前选中的一次 PR。08 阶段随后增加了本地项目 base/head 分支审查模式。

## 完成内容

- `/api/dataset` 仅返回 PR 导航、计数和完整规则目录，不加载全部 Hunk；
- `/api/pr/<number>` 和 `/api/analyze` 返回当前 PR 的完整文件、Hunk、行级 Diff、解析状态、结构证据和评分字段；
- “代码变更”标签页显示接近 GitHub 的统一 Diff，支持文件角色、增删行、Hunk、旧/新行号，以及 rename、delete、binary、解析降级提示；
- “风险规则”标签页公开四条规则的 ID、场景、严重程度、触发条件、证据类型、适用范围、复核建议、当前限制和默认权重；
- 规则命中可以展开到文件、节点类型、结构变化、限定名和 Diff 行，并定位到对应文件和行；
- “评分配置”独立于代码审计视图，只对当前 PR 重算，评分明确标注为人工复核优先级；
- 支持 PR URL 查询参数、PR 抽屉筛选、移动端单列布局和报告导出。

## 启动

先在 `Prisk-System` 目录启动 API：

```powershell
uv run python -m prisk.web_cli
```

再在 `Prisk-System` 目录启动前端：

```powershell
npm --prefix apps/web run start
```

打开 `http://localhost:3000`。开发调试也可使用 `npm --prefix apps/web run dev`。

## 当前限制

当前看板是离线样本和人工复核工具，不是自动缺陷判定系统；规则和评分不读取审查评论、CI 或运行时数据，也不声称确认存在安全缺陷。
